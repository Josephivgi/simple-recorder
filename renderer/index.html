Do not turn this on. It is not a public release. It installs builds from the private development repo, is only for developers of Simple Recorder, and requires a GitHub OAuth sign-in (gh auth login) with access to that repo.

Your data when switching

This copy is a public release.

Moving between public releases and developer builds keeps your settings, takes, and recordings. Before any update installs, Simple Recorder saves a checked copy of its database to the backups folder, named for the build it came from, and installs nothing if that copy fails. Settings one build does not know about stay in place for the build that does.
